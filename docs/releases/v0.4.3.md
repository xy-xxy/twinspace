## TwinSpace v0.4.3 Beta

TwinSpace is a native macOS app duplicator. Select an application, create one managed copy with a blue **2** icon badge, and manage both instances from one window. Copy the application alone or import its existing local data where supported.

### Changes

- **Manual confirmation for source resource differences.** If signature verification reports added, changed, or missing resources, creation pauses and shows the application, source path, differences, and selected copy mode. You can cancel or choose **Confirm and Continue Creating** if you understand and trust the installed application.
- Confirmation applies to the current attempt only and is not saved as a permanent exception. The selected copy mode and custom data directory are retained. Changes to the application version, location, or reported differences require a fresh review.
- The copied application must still pass signing, signature verification, isolation, and startup checks. Tool errors and unsigned applications do not receive this continuation option. Diagnostics record the acknowledgement without reporting the original signature as valid.
- **Drag-to-install DMG.** The disk image contains `TwinSpace.app`, an Applications shortcut, and documentation. Packaging mounts it read-only to verify its contents, signature, version, and both architectures before publishing the artifact. ZIP installers remain available.
- Automated releases now include the DMG in asset verification, uploads, and the SHA-256 manifest. Application identifiers and data locations remain stable.

Requires **macOS 13 or later**. The Universal binary includes Apple Silicon and Intel architectures. The application interface remains Chinese.

1. Quit any running version of TwinSpace. If upgrading from a version with a different app name, remove the old manager bundle from Applications first. Existing application-list data, managed copies, and their data are preserved.
2. Open the DMG and drag `TwinSpace.app` onto **Applications**. Eject the disk image, then open TwinSpace from Applications.
3. This is an **ad-hoc signed beta, not notarized by Apple**. If macOS blocks the first launch, check the download source and follow the instructions in **System Settings → Privacy & Security**. There is no need to disable Gatekeeper or SIP.

### Validation and limitations

- All **70 core checks** and **18 release automation tests** passed. Tests cover approval scope, cancellation, copy-mode retention, preservation after signing or verification failures, and DMG asset integrity.
- A temporary signed application with modified resources was used to verify that an acknowledged build produces a separately signed copy that passes strict system verification while preserving the original files.
- The manager, confirmation dialog, both copy-mode selections, and cancellation were checked on Apple Silicon with macOS 27.0.1. Existing application-list data was preserved.
- **Intel hardware, macOS 13–26, and complete account workflows such as login, messaging, and synchronization have not been fully verified.** Manual confirmation does not establish application compatibility or the trustworthiness of modified files.
- Custom storage, single-instance restrictions, fixed ports, signature requirements, and restricted entitlements can affect compatibility. Importing local data does not export the system keychain or guarantee password and login-session migration.

See the [README](https://github.com/xy-xxy/twinspace/blob/v0.4.3/README.md) and [validation record](https://github.com/xy-xxy/twinspace/blob/v0.4.3/VALIDATION.md) for usage and tested scope.

### Updating copies and removal

After updating an original application, choose Rebuild Copy → Application Only to update its program while preserving its data. Delete Copy and Remove permanently deletes the copied `.app` without using Trash; the original application, account data, and backups are retained.

Report reproduction steps and privacy-reviewed diagnostics in [Issues](https://github.com/xy-xxy/twinspace/issues). Do not include credentials or private application data.
