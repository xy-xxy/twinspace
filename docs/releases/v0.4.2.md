## TwinSpace v0.4.2 Beta

TwinSpace is a native macOS app duplicator. Select an application, create one managed copy with a blue **2** icon badge, and manage both instances from one window. You can copy the application alone or import its existing local data where supported.

### Changes

- The app bundle is now `TwinSpace.app`. The window, menu, sidebar, and diagnostic header use the TwinSpace name.
- Release titles, release notes, and the automatic publishing workflow's fallback notes are now in English, matching the README. The remaining app interface is Chinese.
- Application identifiers and data locations remain unchanged, preserving the application list, managed copies, and their data when upgrading.
- Release verification checks the bundle name and both display-name fields to prevent publishing an installer with outdated branding.

### Download and installation

| File | Contents |
| --- | --- |
| `TwinSpace-0.4.2-macos-universal.zip` | Universal macOS app, English user guide, validation record, and changelog |
| `TwinSpace-0.4.2-source.zip` | Source code, tests, build and release scripts, and documentation |
| `README.md` | English user guide |
| `VALIDATION.zh-CN.md` | Validation record in Chinese |
| `SHA256SUMS.txt` | SHA-256 checksums for the four files above |

Requires **macOS 13 or later**. The Universal binary includes Apple Silicon and Intel architectures.

1. Quit the previous version of TwinSpace. When upgrading, remove the previous manager app from Applications before installing the renamed bundle. Removing the manager bundle preserves your application list, managed copies, and their data.
2. Extract `TwinSpace-0.4.2-macos-universal.zip` and drag `TwinSpace.app` into Applications.
3. This is an **ad-hoc signed beta, not notarized by Apple**. If macOS blocks the first launch, check the download source and follow **System Settings → Privacy & Security** instructions. There is no need to disable Gatekeeper or SIP.

### Validation and limitations

- All 63 core checks and 16 release automation tests passed. Both architecture slices, bundle signatures, release archives, and SHA-256 checksums were checked.
- The renamed manager was opened on Apple Silicon with macOS 27.0.1. Existing application-list data was preserved.
- **Intel hardware, macOS 13–26, and complete account workflows such as login, messaging, and synchronization have not been fully verified.** A successful launch does not establish full compatibility.
- Source integrity verification still runs before copying. If the original application's resources do not match its signature, creation stops and any existing copy is preserved. Reinstall a version with an intact signature from the original distribution channel before retrying.
- Custom storage, single-instance restrictions, fixed ports, signature requirements, and restricted entitlements can affect compatibility. Importing local data does not export the system keychain or guarantee password and login-session migration.

See the [README](https://github.com/xy-xxy/twinspace/blob/v0.4.2/README.md) and [validation record](https://github.com/xy-xxy/twinspace/blob/v0.4.2/VALIDATION.md) for usage and tested scope.

### Updating copies and removal

After updating an original application, choose Rebuild Copy → Application Only to update its program while preserving its data. Delete Copy and Remove permanently deletes the copied `.app` without using Trash; the original application, account data, and backups are retained.

Report reproduction steps and privacy-reviewed diagnostics in [Issues](https://github.com/xy-xxy/twinspace/issues). Do not include credentials or private application data.
