## 双栖 TwinSpace v0.4.1 · 测试版

原生 macOS 应用双开工具。选择原版 `.app`，为每个应用创建一个带蓝色“2”角标的副本，支持仅复制程序或同时复制现有本机资料。

### 下载与安装

| 文件 | 用途 |
| --- | --- |
| `TwinSpace-0.4.1-macos-universal.zip` | 安装包；同时包含 Apple Silicon / Intel 架构，最低 macOS 13 |
| `TwinSpace-0.4.1-source.zip` | 源码、测试、打包脚本和文档 |
| `README.zh-CN.md` / `VALIDATION.zh-CN.md` | 使用说明与验证范围 |
| `SHA256SUMS.txt` | 以上文件的 SHA-256 校验值 |

解压安装包，把“双栖.app”拖到“应用程序”。这是 **本地签名、未经 Apple 公证的测试版**；首次打开如被系统拦截，请确认来源后按照 macOS 的“隐私与安全性”提示操作，无需关闭 Gatekeeper 或 SIP。

### 本版内容

- 原版签名不完整时，显示中文原因和具体新增、变更、缺失资源；复制诊断保留系统校验详情。
- 自动识别原生沙盒、Chromium 浏览器和非沙盒 Electron 的隔离方式；保留 DBX 适配。
- 腾讯文档等 Electron 应用保留原生入口和业务代码，设置独立资料、缓存目录并在启动后检查文件访问路径。
- 复制现有资料前要求退出原版和副本，先备份，再替换；中断后恢复。
- “删除副本并移除”**直接删除副本程序，不进入废纸篓**；原版、账号资料与备份保留。

### 验证与限制

- 63 项自动化检查通过；Universal 二进制与解压后的签名已校验。
- Apple Silicon / macOS 27.0.1 上已对微信、QQ、DBX、Chrome 和腾讯文档完成不同范围的启动、并存或目录检查，详见 [验证记录](https://github.com/xy-xxy/twinspace/blob/v0.4.1/VALIDATION.md)。
- **Intel 真机、macOS 13–26，以及账号登录、消息、文档同步等完整业务功能尚未全面验证。**
- 并非任意应用均可双开；自定义存储、单实例锁、原厂签名依赖、固定端口服务或受限权限仍可能需要专项适配。
- 安装包不包含第三方客户端，不提供插件注入或消息操作。系统钥匙串不导出；复制资料不保证保存的密码或登录态可迁移。

### 更新与卸载

更新双栖不会主动删除现有副本资料。原版应用升级后，在双栖中选择“重建副本 → 仅复制应用程序”。删除副本只删除 `.app`；账号数据需自行确认后另行清理。

遇到问题请在 [Issues](https://github.com/xy-xxy/twinspace/issues) 提交复现步骤及已检查过隐私内容的诊断信息。
