## TwinSpace v0.4.1 Beta

TwinSpace is a native macOS app duplicator. Select an original `.app` to create one managed copy with a blue **2** icon badge. Copy just the application or import its existing local data as well.

### Download and installation

| File | Contents |
| --- | --- |
| `TwinSpace-0.4.1-macos-universal.zip` | Universal macOS app for Apple Silicon and Intel; requires macOS 13 or later |
| `TwinSpace-0.4.1-source.zip` | Source code, tests, build scripts, and documentation |
| `README.md` / `VALIDATION.zh-CN.md` | English user guide and Chinese validation record |
| `SHA256SUMS.txt` | SHA-256 checksums for the four files above |

Extract the installer and drag the included application into Applications. This historical version retains its original Chinese app name and interface. It is an **ad-hoc signed beta, not notarized by Apple**. If macOS blocks the first launch, check the download source and follow the instructions in **System Settings → Privacy & Security**. There is no need to disable Gatekeeper or SIP.

### Changes

- Source integrity failures report added, changed, or missing resources before copying begins. Copy Diagnostics includes the system verification output.
- An isolation strategy is selected according to the application's runtime and storage mechanisms.
- Native entry points and application code are preserved. Separate data and cache locations are configured where supported, with startup and file-path checks.
- Importing data requires both applications to quit. Existing data is backed up before replacement, with recovery after interruption.
- Delete Copy and Remove permanently deletes the copied application without moving it to Trash. The original application, account data, and backups are retained.

### Validation and limitations

- All 63 core checks passed. Universal architecture slices and signatures of extracted bundles were verified.
- Sample startup, concurrent process, and data-directory checks were performed on Apple Silicon with macOS 27.0.1. See the [validation record](https://github.com/xy-xxy/twinspace/blob/main/VALIDATION.md) for the tested scope.
- **Intel hardware, macOS 13–26, and complete account workflows such as login, messaging, and document synchronization have not been fully verified.**
- Compatibility is not universal. Custom storage, single-instance locks, vendor signature requirements, fixed local ports, or restricted entitlements may require further adaptation.
- Packages contain no third-party applications. TwinSpace does not inject plugins or operate messages. The system keychain is not exported; importing local data does not guarantee that passwords or login sessions will transfer.

### Updating and removal

Updating TwinSpace preserves existing copy data. After updating an original application, choose Rebuild Copy → Application Only in TwinSpace. Removing a copy deletes its `.app` only; retained data must be reviewed and removed separately if no longer needed.

Report reproduction steps and privacy-reviewed diagnostics in [Issues](https://github.com/xy-xxy/twinspace/issues).
